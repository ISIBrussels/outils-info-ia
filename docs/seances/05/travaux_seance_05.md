# Séance 5 — Travaux

**Thème :** Google Slides  
**Objectif :** préparer une mini-présentation orale claire (support ≠ document)  
**À rendre :** lien du fichier Slides + PDF de secours

## Travail 1 — Présentation 5–6 slides (obligatoire)

Sujet imposé (choisissez-en un) :

- « Comment je gère Agenda + Drive en 1<sup>e</sup> année ISIB »
- « 5 erreurs à éviter dans un mail scolaire »
- « Du chaos fichiers à une arborescence Drive »

Fichier nommé :

`AAAA-MM-JJ_OutilsInformatiques_Nom_presentation`

Structure minimale :

1. Titre (cours, noms, date)
2. Message / objectif en une phrase
3. 2–3 slides de contenu (une idée par slide)
4. Conclusion / prochaines étapes
5. Questions

Contraintes de forme :

- ≤ **5 puces** par slide, texte court
- Thème / masque homogène (pied de page : cours + noms)
- Au moins **1 visuel** (schéma formes Slides ou capture annotée)

## Travail 2 — Notes d’orateur

Remplissez les **notes** pour au moins 3 slides (ce que vous direz, pas le copier-coller du slide).

## Travail 3 — Répétition et secours

1. Chronométrez une passe (~4–5 min)
2. Exportez un **PDF** de secours dans le même dossier Drive
3. Testez le mode présentation (au moins une fois)

## Travail 4 — Partage groupe (si binôme / trinôme)

Répartissez les slides, partagez en éditeur, et figez le thème avant la « version remise ».

## Critères de réussite

| Critère | Attendu |
| --- | --- |
| Message | Clair dès les 1–2 premières slides |
| Densité | Pas de mur de texte |
| Notes | Présentes pour ≥ 3 slides |
| Secours | PDF déposé + lien Slides accessible |
