## Séance 5

Google Slides

[→ Tâches](taches_seance_05.html)

---

## Objectifs de la séance

- Structurer une présentation : message → plan → slides
- Utiliser **masque** / thème pour l'homogénéité
- Hiérarchiser le texte (peu de mots, titres forts)
- Intégrer images, schémas, liens utiles
- Présenter : notes de l'orateur, mode présentation

---

## Slides ≠ document

| Docs | Slides |
| --- | --- |
| Complet, relisible seul | Support **oral** |
| Détails & annexes OK | Une idée par slide |
| Longueur flexible | Temps chronométré |

Si votre slide est un mur de texte : c'est un Doc déguisé.

---

## Méthode en 4 temps

1. **Message** : en une phrase, que doivent retenir les auditeurs ?
2. **Plan** : 3–5 parties max
3. **Slides** : une idée / slide, titres parlants
4. **Répétition** : chrono + notes orateur

Ne commencez jamais par « joli thème » avant d'avoir le message.

---

## Structure type (10–12 min)

1. Titre + auteurs + contexte
2. Problème / objectif
3. Méthode ou démarche
4. Résultats (2–3 slides)
5. Limites
6. Conclusion / prochaines étapes
7. Questions

Adaptez ; gardez le fil rouge visible.

---

## Design sobre (école / pro)

- Un thème cohérent (couleurs ISIB / neutres)
- Titres courts
- Listes ≤ 5 puces, ≤ 2 lignes chacune
- Beaucoup d'espace blanc
- Police lisible de loin

Évitez : animations tape-à-l'œil, 6 polices, fond photo illisible.

---

## Masque des diapositives

Diapositive → Modifier le masque :

- Position logo / pied de page
- Styles de titres
- Espacement par défaut

Corriger **une fois** au masque plutôt que slide par slide.

---

## Visuels

Bonnes pratiques :

- Schéma simple > paragraphe
- Graphique Sheets → coller lié si besoin de mise à jour
- Captures d'écran annotées (flèche, cadre)
- Créditer les images

Une image doit **clarifier**, pas décorer.

---

## Collaboration sur Slides

- Mode suggestion / commentaires sur une slide
- Répartition : qui prépare quelles parties
- Verrouiller le thème en fin de préparation
- Exporter PDF de secours le jour J

---

## Notes de l'orateur

- Ce que vous dites ≠ ce qui est affiché
- Notes : transitions, chiffres exacts, rappels
- Affichage présentateur : timer + notes + slide suivante

Entraînez-vous **avec** les notes, pas en les découvrant en live.

---

## Accessibilité rapide

- Contraste texte / fond
- Taille de police ≥ ~24 pt pour le corps
- Ne pas coder l'info seulement par la couleur
- Lire à voix haute les slides critiques

---

## Checklist avant présentation

1. Message clair en slide 1–2
2. Homogénéité (masque)
3. Liens / vidéos testés
4. PDF de secours téléchargé
5. Qui parle quoi (si groupe)
6. 1 répétition chronométrée
