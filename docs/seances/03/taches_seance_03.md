## Tâche — Remplir le Doc partagé (3 points)

Ouvrez le **Google Doc** du dossier partagé en séance 2 (enseignant déjà **éditeur**). Travaillez **dans ce fichier** — pas de second Doc.

**Longueur** : **1 page de garde + 3 pages** de corps (**4 pages** au total).

1. **Nom du fichier** (obligatoire) : doit contenir une **date** au format `YYYY-MM-DD_…` (clic sur le titre en haut à gauche) — ex. `2026-10-12_OutilsInfo_rapport-docs`
2. **Page de garde** puis **saut de page** :
   - Titre : **Outils Info & IA**
   - Sous-titre : **Rapport de travail**
   - Votre nom + matricule, groupe, date
3. **Styles** : utilisez **Titre 1**, **Titre 2** et **Titre 3** (au moins un de chaque ; pas du gras manuel). Ces 3 niveaux seuls alimentent la TdM — **pas de Titre 4** dans la table des matières
4. Corps : courte intro (5–8 lignes) sur « Comment j’organise mon travail scolaire avec Google », 1–2 paragraphes utiles, et **une liste numérotée à 4 niveaux** hiérarchiques (`Tab` / `Maj`+`Tab`). Le 4ᵉ niveau reste dans la liste : il n’apparaît **pas** dans la TdM
5. **Table des matières** automatique juste après la page de garde — **uniquement les niveaux 1 à 3** (Titre 1–3)
6. **En-tête / pied** avec **Première page différente** (double-clic en-tête ou pied → cocher l’option) :
   - page de garde : **sans** en-tête/pied du corps (ou contenu distinct)
   - corps : en-tête `Outils Info & IA - Rapport` ; pied = **numéro de page** + **votre nom**
7. Sur **une** sous-section du corps (ex. un chapitre type 3.2.1) : disposition **2 colonnes**, via **sauts de section** avant/après — **pas** tout le Doc en 2 colonnes (`Format` → `Colonnes` → `2` dans la section)
8. **Une figure** avec légende `Figure 1 : …`
9. **2 commentaires** actionnables pour l’enseignant + **1 suggestion** de reformulation
10. **PDF** (`Fichier` → `Télécharger` → `PDF`), nommé en parallèle (aussi avec `YYYY-MM-DD`), déposé **dans le même dossier** Drive

L’enseignant vérifie dans Drive (droits éditeur déjà en place depuis la S2).
