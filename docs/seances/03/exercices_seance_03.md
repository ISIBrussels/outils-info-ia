# Séance 3 — Exercices

**Thème :** Google Docs  
**Durée indicative :** 1 h 30 (intégré au cours, pratique guidée)  
**Support :** compte Google étudiant + navigateur

## Échauffement (5–10 min)

1. Ouvrir un Doc vide ; repérer styles Titre / Titre 1 / Normal.
2. Vote : pourquoi un sommaire échoue si on « fait semblant » avec du gras ?

## Exercices principaux

1. **Structure** : rédiger un mini-rapport (1 page) avec page de garde courte, 2 Titre 1, 2 Titre 2, styles cohérents.
2. **Sommaire** : insérer une table des matières et la mettre à jour.
3. **Collaboration** : laisser 2 commentaires actionnables + 1 suggestion de reformulation.
4. **Figure** : insérer une image avec légende `Figure 1 — …`.
5. **Export** : télécharger en PDF nommé correctement ; vérifier pagination.

## Clôture

- Synthèse : styles → sommaire → collab → PDF. Annonce séance 4 : Sheets.
