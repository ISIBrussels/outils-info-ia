## Objectifs de la séance

- Structurer un document avec **styles** (Titre, Titre 1, Normal…)
- Utiliser sommaire, en-têtes, numérotation de pages
- Collaborer : commentaires, suggestions, historique
- Insérer images, tableaux, liens, signets
- Exporter (PDF) proprement pour une remise

---

## Docs vs traitement de texte local

| Avantage Docs | Limite |
| --- | --- |
| Collaboration temps réel | Mise en page complexe (livres) parfois limitée |
| Historique / suggestions | Dépendance réseau (mode hors ligne possible) |
| Partage par lien | Attention aux droits |

Pour un labo / rapport court : Docs est souvent le meilleur choix en groupe.

---

## Styles : la base de tout

Ne formatez **pas** titre par titre à la main (gras + taille 18).

Utilisez :

- **Titre** — titre du document
- **Titre 1 / 2 / 3** — sections
- **Normal** — corps de texte

Ensuite seulement : modifier le style une fois pour tout homogénéiser.

---

## Sommaire automatique

1. Appliquer Titre 1 / Titre 2
2. Insertion → **Table des matières**
3. Mettre à jour après modifications

Sans styles cohérents → sommaire vide ou absurde.

---

## Page : en-tête, pied, numéros

À mettre systématiquement pour un rendu scolaire :

- En-tête : cours + nom + groupe
- Pied : numéro de page
- Marges raisonnables (évitez le « tout collé »)

Fichier → Mise en page pour format A4.

---

## Collaboration efficace

| Outil | Usage |
| --- | --- |
| Commentaire | question / remarque localisée |
| Mode suggestion | proposer une modification sans écraser |
| @mention | notifier un coéquipier |
| Historique | retrouver qui a changé quoi |

Convention d'équipe : **ne pas supprimer** le travail d'autrui sans discussion.

---

## Commentaires vs chat

- Commentaire **ancré** sur un paragraphe → traçable, actionnable
- Discussion vague hors Doc → se perd

Clôturez les fils résolus (marque « résolu ») pour garder le Doc lisible.

---

## Images et figures

Bonnes pratiques :

- Légende sous la figure (`Figure 1 — …`)
- Taille raisonnable (pas 15 Mo par photo)
- Alt text si pertinent
- Citer la source si image tierce

Alignement : préférez « habillage » simple, évitez le chaos de boîtes flottantes.

---

## Tableaux et listes

- Tableaux pour données structurées (pas pour toute la mise en page)
- Listes à puces pour énumérations
- Listes numérotées pour procédures / étapes

Gardez une colonne d'en-tête claire dans les tableaux.

---

## Liens, signets, titres croisés

- Lien vers une section (signet) plutôt que « voir plus haut »
- Lien Drive vers annexes plutôt que coller 20 pages
- Vérifier les liens avant export PDF

---

## Export et remise

Checklist avant PDF :

1. Styles + sommaire à jour
2. Orthographe (outils → Orthographe)
3. Noms / dates / numéros de figures
4. Fichier → Télécharger → **PDF**
5. Rouvrir le PDF : pages coupées ? images manquantes ?

Nommez : `AAAA-MM-JJ_Cours_Nom_Livrable.pdf`

---

## Modèle minimal de rapport

1. Page de garde (titre, auteurs, date, cours)
2. Sommaire
3. Introduction / objectif
4. Développement (sections Titre 1)
5. Conclusion
6. Annexes (si besoin)

Réutilisez un **modèle** Docs dans votre dossier ISIB.
