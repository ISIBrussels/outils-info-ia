## Travail 1 — Cartographie de situations (obligatoire)

Dans un Doc `AAAA-MM-JJ_OutilsInformatiques_Nom_synthese`, classez **8 situations** (inventez-en de réalistes ou utilisez la liste orale) dans l’une des cases :

| Catégorie | Exemple d’étiquette |
| --- | --- |
| Chat LLM seul | « Explique-moi les filtres Gmail » |
| LLM + sources (type NotebookLM / RAG) | « Interroge mon polycopié » |
| Boucle agentique | « Classe mes mails et crée des tâches Agenda tout seul » |

Pour **3 situations**, justifiez en 2–3 phrases le classement.

## Travail 2 — Schéma de boucle agentique

Insérez un schéma (dessin Docs / capture / Mermaid exporté) :

`objectif → plan → outil → observation → ajustement`

Annotez un exemple concret lié à vos études (ex. préparation d’une réunion projet).

## Travail 3 — « Mes 10 réflexes » Workspace + IA

Rédigez **10 réflexes** actionnables couvrant au minimum : Gmail, Agenda, Drive, Docs ou Sheets ou Slides, Gemini/NotebookLM, éthique.

Pas de slogans vides : chaque réflexe = une action que vous pouvez faire la semaine prochaine.

## Travail 4 — Charte d’usage

Reprenez / finalisez une charte (6 points minimum), ajoutez votre **nom**, section et date.  
Partagez le Doc en lecture avec l’enseignant.
