## Séance 6

Google Slides

Présenter et structurer un support visuel

---

## Objectifs de la séance

- Créer une **présentation** claire : diapo titre, diapos de contenu
- Choisir une **mise en page** (layout) adaptée à chaque diapo
- Harmoniser via le **masque** / **éditeur de thème** (logo, style)
- Structurer le texte : **titres**, puces, une idée par diapo
- Insérer **image**, **formes**, éventuellement un **tableau**
- Préparer l’oral : **notes** du présentateur, mode présentation
- Collaborer : **commentaires**, droits, export **PDF**

---

## À quoi sert Google Slides ?

**Google Slides** = présentation **en ligne**, fichier dans **Drive**.

- Un seul support, pas dix copies `final_v2.pptx`
- Travail à plusieurs sur le **même** fichier
- Présenter depuis le navigateur (salle, visio)

Utile en ingénierie : soutenance courte, protocole de labo, bilan de projet, exposé technique.

PowerPoint reste possible : on peut **importer** / **exporter** `.pptx`. Pour collaborer, préférez le Slides natif.

---

## Interface utile

Zones à connaître :

1. **Filmstrip** à gauche : liste des diapos, glisser pour réordonner
2. **Zone centrale** : diapo active (édition)
3. **Barre d’outils** : texte, formes, image, alignement
4. **Notes** sous la diapo (si affichées) : aide-mémoire pour l’oral

Modes en haut à droite : **Modification**, **Suggestion** (selon droits), **Lecture**.

Bouton **Diaporama** : lancer le mode présentation.

---

## Mise en page (layouts)

Chaque diapo a une **mise en page** : emplacements prêts (titre, corps, deux colonnes…).

**Diapositive** → **Appliquer la mise en page** (ou menu clic droit sur la diapo).

Layouts utiles BA1 :

| Layout | Usage |
| --- | --- |
| **Titre** | Première diapo (titre + sous-titre) |
| **Titre et corps** | Contenu standard (puces) |
| **Titre et deux colonnes** | Comparaison, schéma + texte |
| **Section** | Transition entre parties |

Changer de layout **ne casse** pas forcément le contenu, mais les zones se réorganisent. Vérifiez après.

---

## Thème et arrière-plan

Le **thème** fixe polices, couleurs et styles du deck.

- **Diapositive** → **Changer de thème** : un thème pour tout le fichier
- Arrière-plan d’une diapo : **Diapositive** → **Changer l’arrière-plan**

Règle BA1 : un thème **lisible** (contraste), pas un fond chargé qui mange le texte.

Erreur fréquente : coller du texte blanc sur fond clair (ou l’inverse) après un changement de thème.

---

## Masque et éditeur de thème

Changer de thème = choisir un **préréglage**.  
**Modifier le thème** = éditer les **masques** (modèles derrière les layouts).

**Diapositive** → **Modifier le thème** : ouvre l’**éditeur de thème**.

Dans l’éditeur :

- Polices et couleurs du thème
- Logo, pied de page ou élément répété sur un masque
- Ces éléments s’appliquent à **toutes** les diapos du même layout

BA1 : viser la **cohérence** du deck. Pas besoin de créer plein de masques custom.

Erreur fréquente : recopier logo / pied à la main sur chaque diapo au lieu du masque.

---

## Texte : une idée par diapo

Une bonne diapo se **lit** en quelques secondes, l’oral développe.

| Faire | Éviter |
| --- | --- |
| Titre court + **quelques** puces | Mur de paragraphes |
| Une idée / un message par diapo | Trois sujets mélangés |
| Police assez grande (salle) | Texte minuscule « pour tout caser » |
| Cohérence titre → corps | Titres décoratifs sans lien |

Raccourcis : listes à puces dans la barre d’outils, **Tab** / **Maj**+**Tab** pour les niveaux.

---

## Images

**Insertion** → **Image** (ordinateur, Drive, URL, caméra…).

- Image **lisible** projetée (pas une capture illisible)
- Redimensionner en gardant les proportions (coins)
- Légende ou mention sous / à côté si la figure est citée à l’oral

Disposition : alignez image et texte (guides d’alignement qui apparaissent au déplacement).

Erreur fréquente : image écrasée (proportions cassées) ou trop petite pour la salle.

---

## Formes et alignement

**Insertion** → **Forme** : rectangles, flèches, bulles…

Utile pour : schémas simples, encadrer une idée, flèches de flux.

- Couleur de fond / bordure via la barre d’outils
- **Organiser** → aligner / distribuer si plusieurs objets
- **Grouper** des formes liées (déplacer d’un bloc)

Un schéma clair > dix formes décoratives.

---

## Tableaux (aperçu)

**Insertion** → **Tableau** : petit récap chiffré ou checklist.

| Faire | Éviter |
| --- | --- |
| Peu de lignes / colonnes | Tableau Excel entier collé |
| En-têtes clairs | Cellules trop étroites |
| Lisibilité projetée | Police minuscule |

Pour des calculs ou de grosses données : restez dans **Sheets**, montrez un extrait ou un graphique exporté.

---

## Notes du présentateur

Sous la diapo : zone **Notes** (Affichage → Afficher les notes du présentateur si besoin).

- Aide-mémoire pour **vous** (pas projeté au public par défaut)
- En mode présentation : écran présentateur = diapo + notes + timer

Écrivez des **repères** oraux, pas le texte intégral à lire.

Erreur fréquente : tout mettre sur la diapo faute de notes, puis lire à voix haute.

---

## Transitions et animations

**Transition** : effet entre deux diapos.  
**Animation** : apparition d’un objet sur la diapo.

BA1 : **discret**.

- Une transition simple sur le deck (ou aucune)
- Animations : au plus faire apparaître les puces une à une si utile
- Éviter les effets longs / bruyants en soutenance

Priorité : contenu et rythme oral, pas le spectacle.

---

## Mode présentation

Bouton **Diaporama** (ou **Affichage** → **Diaporama**).

- Flèches / espace : diapo suivante
- Écran présentateur : notes, aperçu suivante, timer
- Pointeur laser / stylo selon le navigateur

Avant le jour J : tester **une fois** en plein écran (salle ou partage d’écran).

Raccourci utile : `Esc` pour quitter.

---

## Collaboration et commentaires

Comme Docs / Sheets : fichier dans Drive, **Partager**.

| Rôle | Effet typique |
| --- | --- |
| **Lecteur** | Voir / présenter selon réglages |
| **Commentateur** | Commentaires, pas d’édition libre |
| **Éditeur** | Modifier les diapos |

Commentaire : sélection → **Commentaire** (demande actionnable).

Suggestion : utile si le droit le permet. Historique des versions : **Fichier** → **Historique des versions**.

---

## Exporter et partager

**Fichier** → **Télécharger** :

- **PDF** : remise, archive, impression
- **PowerPoint** (`.pptx`) : si un outil externe l’exige

Contrôler dans le PDF : ordre des diapos, images présentes, texte non coupé.

Le lien Drive reste la version de **travail**. Le PDF est un **instantané**.

---

## Bonnes pratiques

1. Diapo **titre** claire (sujet, auteur·ice, date / contexte)
2. **Une idée** par diapo, puces courtes
3. Thème lisible, contraste texte / fond, cohérence via le **masque**
4. Images et schémas **lisibles** en projection
5. **Notes** pour l’oral, pas un roman sur la diapo
6. Transitions discrètes, tester le **diaporama** une fois
7. Fichier dans le **dossier Drive** du projet, nommé clairement
